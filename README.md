# Cyber301-Automation-Project

## Project Selected
For this project, I chose Debugging from the book *Automate the Boring Stuff with Python* by Al Sweigart.

## Project Description
I created a simple number guessing game using Python. The computer picks a random number between 1 and 20, and the player has six chances to guess the correct number. The program tells the player if their guess is too high or too low.

I also used Python's logging module to help with debugging. The program records guesses and errors in a file called `debug_log.txt`.

## How to Run the Program
1. Download and install Python.
2. Download the `debugging_project.py` file from this repository.
3. Open the file in VS Code or another Python editor.
4. Run the program using `python debugging_project.py`.
5. Enter numbers to try to guess the correct answer.



## Challenges
One challenge was making sure the program did not crash when someone entered letters instead of numbers. I used error handling to fix this problem. Another challenge was learning how to use logging to record information while the program runs.

## Improvements and Modifications
I added a logging system to help find errors in the program. I also added input checking so the program can handle invalid guesses. These changes make the game easier to use and help with debugging.

## What I Learned
This project helped me understand how debugging works in Python. I learned how to use logging, handle errors, and test my code to make sure it works correctly.
